# README Analytics Setup

Added:
- Live GitHub statistics
- GitHub streak analytics
- Top language analysis
- Live LeetCode statistics, activity, contest and heatmap
- GitHub contribution snake animation
- `.github/workflows/snake.yml` to regenerate the snake daily

After pushing to the `main` branch, run the workflow once from:
GitHub → Actions → Generate Contribution Snake → Run workflow

The workflow publishes generated snake assets to the `output` branch.
